# 🧘 Roommate's Wellness & Music Companion

An open-source, local-first AI assistant built for the Hacktoberfest Weekend Challenge 2026. Powered by **Gemma** via **Ollama** and built using **Streamlit**.

## Features
- 😴 **Sleep & Quality Tracking:** Log sleep hours and quality ratings.
- 📊 **BMI Calculation:** Real-time local health metric calculations.
- 🎵 **Adaptive Music Shuffler:** Context-aware music recommendations based on mood and fatigue.
- 🧘 **Exercise & Nutrition Routines:** Instant stretches and meal advice generated locally.
